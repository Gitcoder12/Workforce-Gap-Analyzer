# Workforce-Gap-Analyzer — Company and Team Fit

**Snapshot:** 2026-11-13

## Project thesis

A web prototype that compares example job opportunities with skill information and can parse a resume to explore possible skill gaps.

Matches below are potential employer/skills fit, not known customers, users, partners, endorsements or hiring interest.

## Microsoft

**Relevant public technical areas:** Workforce analytics, cloud and applied AI.

**Potential role families:** Software Engineer, Backend Engineer, Data Engineer, Applied AI Engineer, Geospatial Engineer or Research Engineer.

**Evidence this project should demonstrate:** Flask application using bundled example job data and PDF/DOCX parsing dependencies. It is not a live labour-market feed or a validated hiring assessment. The existing audit opened issue #3 because the resume upload route reads all bytes without a configured size limit or robust format/content checks.
